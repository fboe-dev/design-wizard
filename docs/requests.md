## 요구 사항

- 프리미티브 탭 고도화
  1. 폰트 페이지
     - 각 컴포넌트 페이지 마다 미리보기 밑에 컨트롤들이 배치되는 레이아웃이 있는데 디자인들이 적합하지 않음.
     - 선택지가 5개 뿐인데 카드만 지원하고 있고 폰트 이름, 예시 등이 너무 대충 만들어진 느낌이 강함.
     - 왼쪽 사이드바를 제외하고 가로 길이를 다쓰는데 이런 UI 레이아웃은 공간낭비가 심함.
     - https://fonts.google.com/ 을 참조해서 내부를 어떻게 효율적으로 채울지 알 수 있으므로 조사.
  2. 타이포그래피
     - 왼쪽 사이드바를 제외하고 가로 길이를 다쓰는데 슬라이더 컨트롤이 가로 길이를 다쓰고 있어서 아주 김.
     - 스케일 미리보기도 위의 문제와 마찬가지. 왼쪽 대부분 공간이 비어있음.
     - 1번처럼 효율적인 레이아웃을 조사할 필요가 있음.
  3. 나머지 페이지들
     - 각 컨트롤을 어떻게 효율적이게 표현할지 조사 필요.
     - 특히 라운딩, 스타일은 내부 컨트롤이 너무 적은데 이렇게 페이지로 나눠야 하는지 모르겠음
     - 차라리 미리보기 밑에 컨트롤 들이 나타나는 페이지가 세로 스크롤 되는 페이지이고 모든 컨트롤이 모여 있어서 왼쪽 사이드바는 단순히 해당 컴포넌트로 이동시켜주는 앵커 역할만 하면 되지 않을까 싶기도 함.
