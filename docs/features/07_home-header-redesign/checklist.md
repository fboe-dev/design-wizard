# 작업별 체크리스트: 07_home-header-redesign

## 체인
refiner → validator(T0) → planner → validator(T1) → designer → validator(T1) → implementer → validator(T2) → orchestrator

## Tier 1 조정
- Designer: **필요** — 플로팅 네비게이션 버튼 (원형 디자인, 기존에 없는 UI 패턴), 헤더 전면 재배치

## Tier 2 추가 항목
- favicon이 브라우저 탭에 정상 표시되는지 확인
- 홈 페이지에 로고 이미지가 가로 5120px 원본 크기로 표시되는지 확인
- 헤더 좌측에 app-icon.png + 'Design Wizard' 텍스트가 표시되는지 확인
- 스텝 인디케이터가 헤더 중앙에 위치하는지 확인
- 다크모드 아이콘이 가장 오른쪽에 outline 스타일로 표시되는지 확인
- 이전/다음 버튼이 원형 플로팅 버튼으로 페이지에 표시되는지 확인
- 홈 페이지에서는 플로팅 버튼이 나타나지 않는지 확인
